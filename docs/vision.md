# Vision

Project must have required elements, but with variable options.
- Board
- Display, options:
    * SSD1306 0.96"
- CO2 sensor, options:
    * SCD40
    * ENS160
- Temperature and humidity sensor, options:
    * SCD40 
    * AHT20
- Current time data, options:
    * RTC with buttons
    * Internet time
